# Data model (prisma/schema.prisma, MySQL) — summary, re-read the schema for exact fields

Conventions: `Int @id @default(autoincrement())`, Persian text in `@db.Text`, money = Int Toman, JSON columns for small lists (`Post.regions`, `Post.neededPositions`, `BlogPost.body`, `DotaMatchStats.*`), singleton settings rows with `id = 1`. Foreign keys with money use `onDelete: Restrict`; social data uses `Cascade`.

## Enums (values)
Rank UNRANKED…IMMORTAL · Position POS1–5 · Region EU_WEST/EU_EAST/RUSSIA/DUBAI · GameMode RANKED_ALL_PICK/ALL_PICK/TURBO/CAPTAINS_MODE · SessionType NOW/SCHEDULED · PostStatus ACTIVE/FULL/EXPIRED/COMPLETED/CANCELLED · MemberStatus PENDING/ACCEPTED/DECLINED/REMOVED · RankVerification SELF_DECLARED/VERIFIED · NotificationType POST_REQUEST, REQUEST_ACCEPTED, REQUEST_DECLINED, NEW_MESSAGE, SESSION_REMINDER, SYSTEM, FRIEND_REQUEST, FRIEND_ACCEPTED, SHOP_ORDER · FriendshipStatus PENDING/ACCEPTED · Report{Status,Severity,Action,Category,Reason} · CommendType FRIENDLY/FORGIVING/TEACHING/LEADERSHIP · AdminResource, PermissionLevel (see architecture.md) · Ticket{Status,Priority,Category} · TestimonialStatus · BlogStatus DRAFT/PUBLISHED/SCHEDULED · AuditAction (≈40 values, one per admin action) · Market{ListingStatus,OrderStatus,TradeMode} · WithdrawalStatus · ShopProductType GIFT_CARD/ITEM · ItemRarity · GiftCodeStatus · ShopOrderStatus · ShopPaymentMethod GATEWAY/WALLET · PaymentStatus · PaymentPurpose ORDER/WALLET_TOPUP/MARKET_ORDER · WalletTransactionType TOPUP/PURCHASE/SALE_INCOME/WITHDRAWAL/REFUND/ADJUSTMENT.

## Core social
- **User**: displayName, email?/phone? (unique), passwordHash, profile (bio, country, languages, rank, rankTier, mainPosition, avatarUrl), Steam (steamId unique, steamProfileUrl, steamTradeUrl), match verification (`matchDataVerified`, `matchGateOverride`), `profileCompletedAt` (onboarding done), `behaviorScore`/`communicationScore` (start 10000, max 12000), commend bonus tracking, notification prefs, session-reminder prefs, payout Sheba/holder prefill, moderation (`banned`, `banReason`, `suspendedUntil`), `roleId`, `lastActiveAt`, `activeChatKey`/`activeChatAt` (chat currently on screen, see features.md), UTM attribution fields.
- **Post** (a lobby): author, position, rank(+tier), gameMode, region + `regions` JSON, `neededPositions` JSON, sessionType/startAt, partySize, voice (hasVoice/voiceLink), status, bumpedAt, expiresAt/expiryWarnedAt (24h auto-expiry, `app/lib/postExpiry.ts`; null = legacy → createdAt+24h). One ACTIVE post per author (enforced in API). Slots logic: `app/lib/postSlots.ts`.
- **PostMember** (join request; unique postId+userId): status, position. A user may be in only one active party (join route checks).
- **Conversation / ConversationParticipant(lastReadAt) / Message** — DMs; `Message.postId` is the lobby group chat; `system` flag for system lines.
- **Notification** (userId, type, title, body?, link?, read, friendshipId?, `groupKey?` + `count` for grouped chat-message rows). **Friendship** one row per pair; declined/cancelled rows are deleted. **Favorite** (note). **Block**.
- **Report** (reporter → user/post/conversation; category/reasonCode/matchId/severity/status/action/scorePenalty/resolvedBy) + **ReportAttachment** (private evidence in `storage/reports`). **Commend** (unique giver+target+match; same-team match verified via OpenDota).
- **DotaMatchStats** (1:1 user): wins/losses, rankTierHint, matches/ratings/totals/heroesPlayed JSON, lastSyncedAt.

## Admin/content
Role, RolePermission, AuditLog(actor, action, targetType, targetId, detail), PlatformSetting, Announcement, BlogPost (slug unique, categories/tags/heroIds as comma strings, body JSON blocks, SEO meta, status), Ticket + TicketMessage(isStaff), Testimonial (1 per user; edit → back to PENDING), ReferenceEntry (category+key lookup rows editable in admin), PasswordResetToken.

## Shop / money
- Shop tables below still contain item/market/withdrawal columns and models from before 2026-10-05; the app no longer reads or writes them (only `GIFT_CARD` products are used).
- **ShopSetting** (id 1): `usdCostToman`, `giftCardMarginPercent`, `itemMarginPercent`, `marketCommissionPercent`, `gatewayFeePercent`, work hours (Tehran) 10–22, `lowStockThreshold`, `minWithdrawalToman`, `payoutHoldHours` 24, `sellerDeadlineHours` 24, `buyerConfirmHours` 72, `mutualConfirmHours` 168.
- **ShopProduct** (type, title, slug? unique Persian, descriptions, imageUrl, features, heroName, rarity, SEO, `priceUsdCents`, `stock?` for items, active, sortOrder). **GiftCode** (encrypted code, unique HMAC hash, hint, status AVAILABLE/ASSIGNED/VOID, orderId?). **ShopOrder** (price/usdCost snapshot, totalToman, tradeUrl snapshot, paidAt, deliveredAt).
- **Payment** (purpose, order/marketOrder ids, amountToman, gateway, `authority` unique, refId, cardPan, status). **WalletTransaction** (append-only signed ledger; `withdrawable`, `availableAt` hold). **WithdrawalRequest** (sheba, holderName, status, processedBy).
- **MarketListing** (seller, Steam asset snapshot assetId/classId/itemName/iconUrl/rarity/heroName, priceToman, `allowDirectTrade`/`allowEscrow`, status). **MarketOrder** (buyer, seller, tradeMode, paymentMethod, price/commission/sellerPayout, buyerTradeUrl, reservedUntil, deadlines & confirmation timestamps, adminTradeUrl, acceptedBy, dispute fields). **MarketOrderAttachment** (private evidence).
